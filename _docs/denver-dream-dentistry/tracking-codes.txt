Findings worth flagging:
- Two GTM containers + two separate GA4 properties (G-TTWGPDEEBJ and G-DSY5CNQZNX) is
  unusual -- normally a site runs one GTM container. This could be leftover from an
  agency handoff/migration, or duplicate/parallel tracking that's splitting or
  double-counting traffic data.
- A live Universal Analytics property (UA-260280036-1) is still wired up. UA stopped
  processing data in mid-2024, so this tag is dead weight -- it fires but nothing
  reads it.
- The Google Maps API key is exposed in a plain client-side URL. This is normal for
  the Maps JavaScript API (it's designed to be public) but it should be
  HTTP-referrer-restricted in Google Cloud Console to denverdreamdentistry.com only --
  worth a quick check, not something we can verify from outside.
